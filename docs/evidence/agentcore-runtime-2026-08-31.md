# AgentCore Runtime Deployment Evidence — August 31, 2026

This record documents a real, short-lived AWS deployment without claiming a continuously hosted
production service. It contains no credentials, raw prompts, personal data, or model output.

## Reproducible evidence

- **AWS Region:** `ap-northeast-1`
- **Source commit:** `b35ef62874b2f377d3c3a93cf0cb34174c60d227`
- **GitHub Actions run:**
  <https://github.com/wellkilo/Quorum/actions/runs/33393010402>
- **Authentication:** GitHub OIDC with short-lived credentials for
  `QuorumAgentCoreDeployerRole`; the workflow rejected any other caller identity.
- **Artifact:** Python 3.13 Linux arm64 CodeZip, 61,251,011 compressed bytes.
- **Observed lifecycle:** `CREATING` → `READY` → verification → `DELETING`.
- **Verification:** the hosted Runtime returned HTTP `503` for the disabled model path. The workflow
  required both a non-zero AWS CLI invocation result and a same-session CloudWatch Runtime event.
- **Cleanup:** the workflow removed the Runtime and private S3 artifact bucket after verification. A
  separate control-plane check returned empty Runtime and workload-identity lists and S3 `404`.

## Cost and safety boundary

No Bedrock model inference was permitted. `QUORUM_BEDROCK_ENABLED=false` blocked the application
path, while the Runtime role independently applied an explicit deny to `bedrock:InvokeModel` and
`bedrock:InvokeModelWithResponseStream`. The one invocation was evidence for Runtime hosting and the
cost gate, not a model-quality result.

The deployment role can manage only the named Quorum Runtime path, its default managed workload
identity lifecycle, one private artifact object, and the associated Runtime logs. Its IAM policy is
generated by `scripts/bootstrap_agentcore_iam.sh` and covered by an executable regression test.

## What this proves — and what it does not

This run proves that the reviewed CodeZip can be deployed to AgentCore Runtime, become ready, receive
an IAM-authenticated invocation, fail closed before model construction, emit session-correlated
Runtime evidence, and clean itself up.

It does not claim a public anonymous AgentCore endpoint, a Bedrock model result, a live PostgreSQL
service, AgentCore Memory or Gateway deployment, an end-to-end Slack/Google Workspace call, or
real-world community impact. The anonymous demo remains the visibly synthetic GitHub Pages replay.
