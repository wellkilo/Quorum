# Quorum First 72 Hours: Fast Track

The objective is to produce judge-visible evidence quickly while preserving the project's truth boundary. Items are ordered by score impact and dependency, not by calendar date.

## Hour 0–6: establish an eligible, auditable project

- [x] Register for Devpost.
- [x] Request USD 50 in AWS promotional credits.
- [x] Create the public repository target.
- [x] Add an Apache-2.0 license in the first commit.
- [x] Add an English README with limitations and reuse disclosure.
- [x] Record the verified competition rules and SDK capabilities.
- [x] Add real-data consent and local-redaction safeguards.
- [ ] Confirm GitHub detects the license after the first push.
- [ ] Add the actual AWS Builder ID to the private submission checklist.

## Hour 6–24: obtain an evidence path

- [ ] Send the three interview guides to three plausible small organizations.
- [ ] Request a 20-minute workflow interview before requesting any export.
- [ ] Select one pilot candidate and one fallback candidate.
- [ ] Record authority, reversibility, timeout, and interruption expectations.
- [ ] Seek separate authorization for a one-week export and for any quotation.
- [ ] If no organization is available, continue with synthetic data without making an impact claim.
- [ ] Create the first synthetic week with `data_classification: synthetic`.
- [ ] Define exact metric formulas before observing outcomes.

## Hour 24–48: prove one vertical slice

- [ ] Create a Slack test workspace and app.
- [x] Version and offline-validate the minimal-permission Socket Mode app manifest.
- [ ] Receive and verify one real Slack Events API callback.
- [x] Implement and test the shared PII-safe canonical event conversion boundary.
- [x] Exercise the signed HTTP ingress locally with valid, forged, and cost-gated requests.
- [x] Run Listener -> Ledger Curator in a Strands Graph contract test.
- [x] Reject a commitment that lacks `source_message_ref`.
- [x] Keep session state and business-ledger persistence separate and executable.
- [x] Display the primary counter: interruptions used versus budget.
- [x] Add focused unit and integration tests for the Slack transport slice.

## Hour 48–72: make the product claim visible

- [x] Add deterministic risk classification for reversibility, impact radius, and money.
- [x] Add a `BeforeToolCallEvent` autonomy hook.
- [x] Demonstrate native Strands interrupt and resume in executable local tests.
- [x] Implement and test one group receipt with a working undo action.
- [x] Implement and test one private question with a timeout and explicit default.
- [x] Generate one weekly one-screen summary from synthetic data.
- [x] Capture one managed synthetic OTEL span without raw message content or downstream calls.
- [ ] Record a 30-second evidence clip for the eventual demo.
- [ ] Review and publish the first Builder Center post.

## Scope freeze gate

Freeze six target task classes only after interviews provide evidence. Until then, no task class is described as validated. After the freeze, additions require a written estimate of which judging criterion improves and what visible evidence the feature adds.

## Exit evidence

The fast track is complete only when a clean machine can run the tests, a Slack message produces an evidence-linked ledger row, a policy decision either stays silent or raises a native interrupt, and the dashboard visibly counts the interruption.
